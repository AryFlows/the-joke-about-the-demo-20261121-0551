A one-line joke about working beside an AI coding agent, set in a live demo in front of a room. The agent is flawless all morning, then fixes the bug on stage — and turns to the audience to apologise for the human's prompt.

> My AI agent worked perfectly all morning — then, in front of fifty people, it fixed the bug and apologised to the room for my prompt.

## Why this joke

The demo room is where the agent's confidence and the human's authority collide: the machine is the hero on stage, and the human is the one left apologising by proxy. No setup is explained — the room, the fix, and the apology do all the work in one line.

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt`. Set `OUTPUT_DIR` to write somewhere else:

```sh
OUTPUT_DIR=./out node main.ts
```
